# FMD Outbreak Prediction Model — Sri Lanka (2017–2024)

This repository contains the research code for predicting Foot-and-Mouth Disease (FMD) outbreaks across 25 districts in Sri Lanka, using machine learning techniques on environmental, spatial, and meteorological data.

## 📂 Project Structure

The project has been organized into numbered Jupyter Notebooks to clearly demonstrate the research workflow from raw data to final predictions.

```text
├── data/
│   ├── raw/                          ← Original raw datasets (CHIRPS, DAPH, GLW, Admin Boundaries)
│   ├── processed/                    ← Processed and merged data files
│   │   ├── while Processing/         ← Intermediate steps
│   │   └── FMD_model_ready_main refined_final_dataset.csv  ← Final model-ready dataset
│
├── notebooks/                        ← Main project code
│   ├── 01_Data_Collection_and_Understanding.ipynb
│   ├── 02_Data_Preprocessing_and_Feature_Engineering.ipynb
│   ├── 03_Exploratory_Data_Analysis.ipynb
│   ├── 04_Model_Training_and_Evaluation.ipynb
│   └── 05_Final_Model_and_Predictions.ipynb
│
├── plots/                            ← Visualizations generated by the notebooks
│   ├── 01_data_overview/
│   ├── 03_eda/
│   ├── 04_model_comparison/
│   └── 05_final_predictions/
│
└── models/                           ← Saved trained machine learning models
```

## 🚀 How to Run the Project

To reproduce the research, open and run the notebooks in sequential order:

1. **`01_Data_Collection_and_Understanding.ipynb`**: Explores the raw data sources (DAPH outbreaks, CHIRPS rainfall, GLW livestock density, Admin boundaries) to understand baseline structures and coverage.
2. **`02_Data_Preprocessing_and_Feature_Engineering.ipynb`**: Explains the data merging process and feature engineering (cyclical time encoding, monsoon phases, weather lags).
3. **`03_Exploratory_Data_Analysis.ipynb`**: Analyzes class imbalances, outbreak distributions across districts/months, and feature correlations.
4. **`04_Model_Training_and_Evaluation.ipynb`**: Evaluates models (Logistic Regression, Random Forest, Gradient Boosting, XGBoost) against a Seasonal Naive baseline using walk-forward time-series cross-validation.
5. **`05_Final_Model_and_Predictions.ipynb`**: Trains the final chosen model on 2017-2023 data and generates predictions, probability heatmaps, and district risk rankings for 2024.

## 📊 Evaluation Strategy
Because FMD outbreaks are temporally dependent, random train-test splitting is inappropriate. The models were evaluated using **expanding-window walk-forward validation**:
* Train 2017-2021 → Test 2022
* Train 2017-2022 → Test 2023
* Train 2017-2023 → Test 2024
